DetectionBall 
Проект: Система детектирования футбольного мяча в видео с веб-интерфейсом на Django

Описание:
1. Приложение позволяет загружать видео с футбольными матчами, выполнять инференс предобученной модели YOLO для детектирования мяча и создавать анимированные GIF с визуализацией траектории и траектории мяча. Результаты и история обработок сохраняются в базу данных и доступны для скачивания отчёта в формате PDF.
Возможности;
2. Загрузка входного видео (MP4) через веб-интерфейс;
3. Инференс и сглаживание трекинга мяча (YOLO + усреднение по кадрам);
4. Генерация высококачественного GIF с подчёркнутыми рамкой и надписями;
5. Сохранение входных и выходных файлов в папке media/;
6. История запросов в модели VideoDetection (PostgreSQL);
7. Автоматическое копирование артефактов в reports/gifs/ и reports/videos/;
8. Скачивание PDF-отчёта по истории обработок.

Требования:
1. Python 3.9+;
2. Django 4.x;
3. ultralytics (YOLO);
4. OpenCV (cv2);
5. imageio;
6. psycopg2-binary (если PostgreSQL);
7. reportlab, pandas, openpyxl (для отчётов).

Этапы установки:
1. Клонировать репозиторий:
    1. `git clone https://github.com/Quant60/DetectionBall.git`
    2. `cd DetectionBall`
2. Создать виртуальное окружение и активировать:
    1. `python -m venv .venv`
    2. `.venv/Scripts/activate`    # Windows
    3. `source .venv/bin/activate` # Linux/MacOS
3. Установить зависимости:
    1. `pip install -r requirements.txt`
4. Настроить БД
    1. Отредактировать`setting.py`
5. Применить миграции:
    1. `python manage.py migrate `
6. Запустить сервер:
    1. `python manage.py runserver `
